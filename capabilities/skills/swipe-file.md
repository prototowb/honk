# Swipe File — technique research, not topic research

Distinct from `research-trends` (finds *what's worth posting about*): this finds
**how the best posts in this niche are actually built** — hook mechanics,
structural shape, visual approach — and distills reusable patterns into the
current draft. Honk has no competitive-intelligence API — you do this with your
own research ability (web search, the user's supplied examples/handles) and
bring back **patterns**, not screenshots to imitate line-by-line.

## Process

1. **Gather 3–5 reference posts** — accounts in the brand's niche (or the
   user's named competitors/inspirations), on the **same platform** you're
   drafting for (technique is platform-specific — an X hook doesn't transfer
   to an IG carousel as-is; see each `post-to-*` skill's own "what the
   algorithm rewards" section for the platform's mechanics). Prefer posts that
   visibly did well (replies/saves/shares/quote volume, when visible) over
   just-recent ones.
2. **For each, extract the pattern, not the content:**
   - **Hook mechanism** — question, contrarian claim, specific stat, POV framing, tension?
   - **Structural shape** — single sharp claim, listicle, narrative arc, before/after?
   - **Format choice** — text-only, single image, carousel, thread — and why
     that shape suits the idea?
   - **Visual approach** (if applicable) — text-card, photo, screenshot,
     UGC-style — and how the on-image text relates to the caption (see
     `content-craft` §6, image-text coherence).
   - **What likely drove the response** — a save-worthy framework, a
     share-worthy truth, a reply-inviting question? (See `content-craft` §1.)
3. **Synthesize 2–3 patterns** relevant to the current brief/draft — name the
   *technique*, not the *source*: "a contrarian-claim hook, then a specific
   number that backs it up" — not "do what @account did."
4. **Never copy** phrasing, data, or claims from the reference posts into the
   draft. Borrow *structure*, never *content* — if a stat catches your eye,
   trace it to its own primary source before using it
   (`pipeline-orchestrator`'s sourcing rule applies regardless of where you
   found it).

## Output

A short "technique note" — the pattern(s) chosen and why they fit this brief —
attached to the draft or brief, not a separate deliverable. Hand off to
`content-craft` for drafting, or to the relevant platform skill if a pattern is
platform-specific (e.g. carousel arc, thread structure).

## When to use it

- On request ("what's working for [niche/competitor] right now on IG?").
- Optionally offered alongside `research-trends` when a brief needs a fresh
  angle **and** a fresher format — topic research finds *what*, this finds *how*.
- Before a platform or format the brand hasn't used much yet, to ground the
  first attempt in what's already working there rather than guessing cold.

## Guardrails

- **Technique, never content.** Adapting a format or hook style is normal
  craft practice; reusing another account's specific words, data, or
  distinctive assets is not — and undermines the "specific, source-verified"
  bar this project holds itself to (`content-craft` §3, `pipeline-orchestrator`
  sourcing).
- **Platform-specific.** A pattern proven on X doesn't necessarily transfer to
  Instagram — re-derive fit for the target platform rather than porting verbatim.
- **Small sample, directional.** A handful of reference posts is a prompt for
  ideas, not a study — treat patterns as worth trying, not proven for this
  brand. Platform mechanics also shift over time; see each `post-to-*` skill's
  own hedge on that.
